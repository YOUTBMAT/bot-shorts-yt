# Pillow: teto aberto proposital (>=10.4.0, sem <11/<12). `Image.ANTIALIAS`
# foi REMOVIDO no Pillow >= 10.0 (era usado por moviepy 1.0.3 como fallback
# do resizer quando o OpenCV/cv2 não está disponível — e este projeto NÃO
# depende de opencv), o que quebraria TODO `.resize()` de clip (Ken Burns e
# redimensionamento do vídeo de fundo) com
# `AttributeError: module 'PIL.Image' has no attribute 'ANTIALIAS'`. Isso é
# corrigido em runtime por um shim no início de bot_main.py
# (`Image.ANTIALIAS = Image.Resampling.LANCZOS` se o atributo não existir),
# então não há mais necessidade de pin exato numa versão antiga do Pillow:
# qualquer Pillow >= 10.4 funciona, incluindo as versões com wheel para
# Python 3.14 (verificado: Pillow já publica wheel cp314 no PyPI).
Pillow>=10.4.0
