# google-genai: pin de major para evitar quebras (o SDK mudou bastante entre

# Pillow: PIN EXATO, não relaxar — CRÍTICO, não é só preferência de
# estabilidade. moviepy 1.0.3 usa `Image.ANTIALIAS` como fallback do
# resizer quando o OpenCV (cv2) não está disponível — e este projeto NÃO
# depende de opencv. `Image.ANTIALIAS` foi REMOVIDO no Pillow >= 10.0,
# quebrando TODO `.resize()` de clip (usado no Ken Burns e no
# redimensionamento do vídeo de fundo). Reproduzido e confirmado em teste
# isolado: com Pillow >= 10 e sem cv2, `clip.resize(...)` lança
# `AttributeError: module 'PIL.Image' has no attribute 'ANTIALIAS'`.
# A versão 9.5.0 tem wheel pré-compilada para cp310 manylinux (Python 3.10,
# usado no agendador.yml), então instala normalmente no GitHub Actions sem
# precisar compilar do zero.
Pillow==9.5.0
